# Release notes

Copies of the upstream release notes, fetched once by `statdrift notes` from the pinned
commits in `configs/study.toml` and hashed in `MANIFEST.json`. SciPy and statsmodels are
BSD-3-Clause licensed; these files are theirs and are kept unchanged so the documented-share
analysis can be rerun. statsmodels has no notes file for 0.14.5 and 0.14.6, so the bodies of
their GitHub releases stand in.
